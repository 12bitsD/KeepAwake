# 不熄屏 KeepAwake

一个轻量、原生的 macOS 菜单栏防熄屏应用。使用 Swift 和 AppKit 编写，无第三方依赖，不联网，不修改系统电源设置。

## 功能

- 菜单一键开启或关闭防熄屏
- 同时阻止显示器睡眠和系统闲置睡眠
- 预设 1 分钟、15 分钟、30 分钟、1 小时和无限期
- 支持自定义 1–10080 分钟的保持时长
- 显示倒计时，到期自动恢复
- “到时自动息屏”默认开启，有限时长到期后立即关闭显示器
- “合盖保持唤醒”默认开启，接通电源时阻止合盖系统睡眠
- 记住上次选择的时长和各功能选项
- 退出应用时自动清理防休眠进程
- 仅驻留菜单栏，不占用 Dock

## 系统要求

- macOS 12.0 或更高版本
- 构建时需要 Swift 编译器（可通过 Xcode Command Line Tools 提供）
- 合盖保持唤醒需要连接电源适配器

## 构建

```bash
git clone https://github.com/12bitsD/KeepAwake.git
cd KeepAwake
./build.sh
open build/KeepAwake.app
```

构建产物位于 `build/KeepAwake.app`。脚本会为当前机器架构编译原生可执行文件。

安装到当前用户的应用目录：

```bash
INSTALL_DIR="$HOME/Applications" ./build.sh
open "$HOME/Applications/KeepAwake.app"
```

## 使用

1. 点击菜单栏中的杯子图标。
2. 在“保持时长”中选择预设时间，或点击“自定义时长…”输入整数分钟数，默认是“无限期”。
3. 点击“开启防熄屏”。图标变为实心杯子时表示正在保持唤醒。
4. 点击“关闭防熄屏”可立即恢复；选择“退出不熄屏”也会停止防休眠。
5. “到时自动息屏”默认开启，可在菜单中取消勾选。
6. “合盖保持唤醒”默认开启，需连接电源适配器。合盖后内置显示屏会关闭，但系统继续运行。

应用启动后不会自动开启防熄屏，需要手动启用。只有有限时长自然倒计时结束时才会自动息屏；选择无限期、手动关闭或退出应用都不会触发息屏。

## 工作原理

开启且启用合盖模式时，应用启动 macOS 自带的工具：

```bash
/usr/bin/caffeinate -dis -w <KeepAwake 进程 PID>
```

- `-d`：阻止显示器闲置睡眠。
- `-i`：阻止系统闲置睡眠。
- `-s`：阻止系统睡眠，包括接通电源时的合盖睡眠。
- `-w`：跟随 KeepAwake 的进程生命周期，应用退出时自动结束。

关闭合盖模式时使用 `-di`，不添加 `-s`。在保持唤醒期间切换合盖模式会重新启动 `caffeinate`，并保留原倒计时。

定时由应用自身管理。手动关闭、倒计时结束和正常退出都会终止对应的 `caffeinate` 子进程。有限时长自然到期且开启“到时自动息屏”时，应用还会运行：

```bash
/usr/bin/pmset displaysleepnow
```

该命令只请求显示器睡眠，不执行锁屏命令。

## 限制

- 合盖保持唤醒仅在连接电源适配器时有效，电池模式下不保证阻止合盖睡眠；应用不会通过管理员权限修改系统电源设置。
- 合盖保持唤醒是让系统继续运行，不是让 MacBook 内置显示屏在合盖后继续亮着。
- 不阻止屏幕锁定，也不绕过系统安全设置。如果 macOS 设置了“显示器关闭后立即要求密码”，自动息屏后系统仍会按该策略锁定；应用不会修改此设置。
- 不覆盖管理员或其他系统策略强制的电源设置。
- 当前为本地构建的未签名应用，未提供经过 Apple 公证的安装包。
